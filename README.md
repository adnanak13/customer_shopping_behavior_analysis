# Customer Shopping Behavior Analysis

An end-to-end data analytics project that explores customer shopping behavior to identify purchasing patterns, customer segments, product preferences, discount usage, shipping preferences, and subscription behavior. The project combines **Python, SQL, Power BI, and business reporting** to turn a retail shopping dataset into actionable recommendations.

## Project Objective

The business goal is to understand how customer shopping data can be used to improve sales, customer engagement, customer satisfaction, and long-term loyalty. The analysis focuses on how demographics, product categories, discounts, reviews, shipping, and subscription status relate to customer purchasing behavior.

## Dataset Overview

The dataset contains **3,900 records and 18 original columns**.

Key fields include:

- **Customer details:** Customer ID, age, gender, and location
- **Purchase details:** Item purchased, category, purchase amount, season, size, and color
- **Shopping behavior:** Previous purchases, frequency of purchases, review rating, discount applied, and promo code usage
- **Order preferences:** Subscription status, shipping type, and payment method

The report identifies **37 missing values in the Review Rating column**.

## Workflow

### 1. Data Preparation with Python

The notebook follows these preparation steps:

1. Load the CSV dataset with pandas.
2. Inspect the data using methods such as `info()`, `describe()`, and null-value checks.
3. Fill missing review ratings using the median rating within each product category.
4. Standardize column names to lowercase snake case and rename the purchase amount field to `purchased_amount`.
5. Create an `age_group` feature by dividing customer ages into four quantile-based groups: Young Adult, Adult, Middle-aged, and Senior.
6. Map purchase-frequency labels to an estimated number of days in a new `purchase_frequency_days` column.
7. Compare `discount_applied` and `promo_code_used`; the notebook checks whether they match and drops `promo_code_used`.
8. Load the prepared DataFrame into a database table for SQL analysis.

**Note:** The notebook contains example local database connection settings. Update them for your own environment and do not publish real passwords or credentials in the repository.

### 2. Business Analysis with SQL

The SQL file addresses these ten business questions:

1. How much revenue is generated by male and female customers?
2. Which customers used a discount but still spent at least the average purchase amount?
3. Which five products have the highest average review ratings?
4. How do average purchase amounts compare between Standard and Express shipping?
5. How do subscriber and non-subscriber customer counts, average spend, and total revenue compare?
6. Which five products have the highest percentage of purchases with a discount?
7. How many customers fall into New, Returning, and Loyal segments based on previous purchases?
8. What are the three most purchased products within each category?
9. How many repeat buyers (more than five previous purchases) are subscribers versus non-subscribers?
10. How much revenue does each age group contribute?

The SQL script expects a database named `customer_behavior` and a table named `mytable`. Create the database, load the cleaned dataset into the expected table, and confirm that the SQL dialect matches your database server before running the queries.

## Key Findings Reported in the Presentation

The presentation highlights the following findings:

- Female customers generate slightly higher total revenue than male customers.
- Express-shipping customers spend about **$65 per purchase**, compared with about **$58** for Standard shipping; the presentation describes this as approximately 12% higher.
- The presentation reports higher spending among subscribers and a 45% revenue share from subscription customers.
- Customer segmentation is presented as approximately 50% New, 35% Returning, and 15% Loyal.
- Blouse, Dress, and Shirt are highlighted among the top-rated products.

These figures are reported in the supplied presentation and should be validated against the final cleaned dataset, SQL results, and Power BI measures before being used for business decisions.

## Business Recommendations

Based on the supplied project report and presentation:

- **Encourage subscriptions:** Communicate subscriber benefits and test offers that support sign-ups.
- **Improve customer retention:** Reward repeat purchases and help returning customers become loyal customers.
- **Review discount strategy:** Evaluate discount effectiveness while monitoring profitability.
- **Promote popular products:** Feature highly rated and frequently purchased products in campaigns.
- **Use targeted marketing:** Tailor campaigns to high-revenue customer segments and examine shipping preferences.
- **Validate results:** Check that the SQL queries, dashboard measures, and report use consistent definitions and totals.

## How to Run the Project

### Requirements

- Python 3
- Jupyter Notebook
- pandas
- A supported SQL database and client
- Power BI Desktop (for the `.pbix` dashboard)

### Steps

1. Clone or download this repository.
2. Place `customer_shopping_behavior.csv` in the same working directory as the notebook.
3. Install the Python dependency:
   ```bash
   pip install pandas sqlalchemy pymysql
   ```
   The notebook uses SQLAlchemy and PyMySQL for its example database connection.
4. Open `Customer_Shopping_Behavior_Analysis.ipynb` in Jupyter Notebook and run the cells in order. Review and update the database connection settings first.
5. Ensure the cleaned data is loaded into the `mytable` table in the `customer_behavior` database.
6. Open `Cust_bhvr.sql` in your SQL client and run the queries against the prepared table. The script uses `USE`, `LIMIT`, and window functions; confirm compatibility with your database version.
7. Open `customer_behavior_dashboard.pbix` in Power BI Desktop. If prompted, update data-source paths or credentials and refresh the data.
8. Review the PDF report and PowerPoint presentation for the documented workflow, findings, and recommendations.
